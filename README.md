# نظام إدارة الليدز والمبيعات (CRM)

نظام CRM بسيط لإدارة ليدز الإعلانات وتوزيعها على مناديب المبيعات، مع مخطط مبيعات (Kanban)، متابعة SLA لزمن الرد، وتقارير دورية.

افتح [`crm/index.html`](crm/index.html) في المتصفح لتشغيل النظام. البيانات تُحفظ محليًا في متصفحك (localStorage) بدون الحاجة لسيرفر أو قاعدة بيانات.

## الميزات
- **الليدز**: استقبال، بحث، فلترة، وتوزيع تلقائي أو يدوي على المناديب.
- **مخطط المبيعات**: لوحة Kanban بمراحل البيع (جديد ← تم التواصل ← مؤهل ← عرض سعر ← تفاوض ← صفقة ناجحة/خسارة) بالسحب والإفلات.
- **مناديب المبيعات**: إدارة المناديب ومتابعة أداء كل واحد منهم.
- **SLA**: تنبيهات فورية عند تأخر مندوب عن أول رد أو متابعة العميل، مع تقرير التزام لكل مندوب.
- **التقارير**: إحصائيات حسب المصدر، الحالة، والمندوب، مع تصدير CSV.
