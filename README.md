# معرض رواد الاعتماد للسيارات

- `index.html` — موقع المعرض مع حاسبة التمويل.
- `inventory/` — **نظام إدارة المخزون** (لوحة تحكم داخلية للموظفين).

## نظام إدارة المخزون

افتح `inventory/index.html` (أو `/inventory/` على GitHub Pages). يعمل بالكامل في المتصفح بدون سيرفر.

**المزايا**
- لوحة تحكم: قيمة المخزون، الربح المتوقع، مبيعات الشهر، متوسط عمر المخزون، مخطط مبيعات 6 أشهر، وتنبيهات ذكية (سيارات متقادمة، حجوزات منتهية، هوامش منخفضة، صيانة متأخرة).
- السيارات: إضافة/تعديل/حذف، بحث وفلترة وترتيب، رقم مخزون تلقائي، منع تكرار رقم الهيكل (VIN)، سجل زمني لكل سيارة.
- دورة حياة السيارة: في الطريق ← متاحة ← محجوزة (بعربون وتاريخ انتهاء) ← مباعة، مع الصيانة والنقل بين الفروع.
- المبيعات: فاتورة ضريبية قابلة للطباعة (ضريبة القيمة المضافة)، طرق الدفع وجهات التمويل، إلغاء بيع / مرتجع.
- المصاريف: تُحمَّل على تكلفة السيارة وتنعكس على صافي الربح.
- الموردون، سجل حركات كامل (تدقيق)، تقارير (أعمار المخزون، الفروع، أداء الماركات والبائعين).
- تصدير Excel (CSV)، طباعة كشف جرد وبطاقة سعر السيارة، نسخ احتياطي واستيراد.

**ملاحظة مهمة:** البيانات تُحفظ في متصفح الجهاز (localStorage). خذ نسخة احتياطية دوريًا من الإعدادات. عند أول تشغيل تظهر بيانات تجريبية — امسحها من الإعدادات قبل البدء الفعلي.
